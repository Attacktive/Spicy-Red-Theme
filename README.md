# Spicy Red Theme

This is a **customized Chrome theme** with colors inspired by the Spicy red theme from Microsoft Edge.

| Surface | Color |
| --- | --- |
| Active frame/sidebar | `#570F13` |
| Selected tab and toolbar | `#6F161C` |
| Inactive frame/sidebar | `#570F13` |

Chrome uses the same `toolbar` theme color for its selected tab and browser toolbar, while Edge colors those surfaces separately (highlighting only the active tab while keeping the top toolbar dark). Using `#6F161C` for `toolbar` and `#570F13` for `frame` and `frame_inactive` preserves active-tab contrast without over-brightening the top toolbar, while letting Chrome dim the unfocused frame rather than brightening it.
